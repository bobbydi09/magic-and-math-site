# Магия и Математика — официальный сайт

Лендинг образовательной фэнтези-RPG «Магия и Математика».
Статический сайт без сборки, опубликован на GitHub Pages:
https://bobbydi09.github.io/magic-and-math-site/

## Структура

```
index.html               разметка и тексты страницы
Academy.png              оригинал главного изображения (не заменять)
assets/
  css/style.css          оформление
  js/config.js           настройки: релиз, цены, ссылки
  js/main.js             логика: мобильное меню и подстановка настроек
  images/academy.webp    оптимизированная копия Academy.png для первого экрана
  favicon.svg            иконка вкладки
```

## Что менять после выхода игры

Всё, что меняется со временем, находится в `assets/js/config.js`:

| Что | Где в `config.js` |
|---|---|
| Статус релиза (`"planned"` → `"live"`) | `releaseStatus` |
| Тексты о релизе (главный экран и FAQ) | `releaseText` |
| Цены | `price.free`, `price.paid` |
| Ссылка на установку | `downloadUrl` |
| Telegram, ВКонтакте, MAX, YouTube, контакт автора | `links` |

Пустая ссылка автоматически скрывает соответствующую кнопку.
Кнопка «Скачать игру» появляется только когда статус `"live"` и заполнен `downloadUrl`.
Цены указаны в нескольких местах страницы, но подставляются из `config.js`.

## Что добавить, когда будут материалы

- **Логотип.** Положить утверждённый файл в `assets/images/` и заменить символ ✧
  в блоках `.brand` и `.mark` в `index.html`.
- **Скриншоты игры.** Добавить реальные кадры в `assets/images/`. Блоки раздела
  «Учиться — значит понимать» в `index.html` можно дополнить изображением.
  Макеты интерфейса не использовать.
- **Портрет Алатора.** Добавить утверждённое изображение в `assets/images/`
  и поместить его в подходящий раздел.
- **Open Graph-превью.** Текущее превью — `Academy.png`. При появлении отдельной
  картинки для соцсетей указать её в `og:image`.

## Проверка перед публикацией

- Открыть `index.html` в браузере и проверить мобильную и десктопную версии.
- Проверить, что на сайте нет технических пометок вроде «временный макет»
  или «заменить изображение».
- Проверить, что ссылки в `config.js` заполнены верно, а пустые кнопки скрыты.
- Для проверки в Chrome или Chromium: открыть страницу, нажать мобильное меню
  и прокрутить до каждого раздела.

## Публикация

GitHub Pages публикует ветку `main`. Изменения отправляются обычным `git push`
без перезаписи истории.
